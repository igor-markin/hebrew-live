# Живой экран: замеры 23.11.2026

Повтор записей через приложение в реальном времени: `he-ru benchmark WAV --ui browser --publication draft`, окно открыто в headless Chrome (`experiments/corpus/window_watch.mjs`), окно пишет в журнал всё, что нарисовало (`ui_render`). Итоги по сеансу: `summary.json` (`src/hebrew_live/session_summary.py`). Скрипт: `experiments/corpus/replay_variants.py`. MacBook Air M5 16 ГБ.

Записи: четыре свои (25, 55, 56, 106 с) и три записи eval-whatsapp (66, 72, 94 с). Записи в репозиторий не входят.

## Решение

По умолчанию теперь: спокойные черновики (`HEBREW_LIVE_CALM_DRAFTS`), расписание 0,7/0,7 с (`tuning.DEFAULTS`), черновик перевода из прошлой версии с допуском 0,3 (`HEBREW_LIVE_MT_SPECULATE`). Откат: `HEBREW_LIVE_CALM_DRAFTS=0`, `HEBREW_LIVE_TIMING=1,1,0,4,0.6`, `HEBREW_LIVE_MT_SPECULATE=0` (вариант `previous`).

Гибрид (`HEBREW_LIVE_HYBRID=1`, `HEBREW_LIVE_HYBRID_MODEL=папка zipformer2-66m-streaming-he`) остаётся за флагом и в приложение не упакован.

## Экран

Иврит над переводом всегда (раньше — под «Оригиналом»), перевод 20 px, иврит 15 px. Новый иврит открытой фразы приходит сразу после распознавания (`live_source`), не дожидаясь перевода. Неподтверждённые слова перевода серые, числа, время, даты и суммы выделены. Один прогон 55-секундной записи до и после: иврит на экране p50 0,75 → 0,43 с, перевод p95 1,51 → 1,09 с, стёрто слов перевода 178 → 42.

## Не измерено

- Качество перевода против эталонов с `MT_SPECULATE` (допуск 0,3 принимает почти равные токены, перевод может отличаться синонимом или точкой).
- Гибрид вместе с `MT_SPECULATE`; почему у гибрида стирается больше слов перевода.
- Реальный звонок по телефону; нагрев.
- Разброс: по одному прогону на вариант.
