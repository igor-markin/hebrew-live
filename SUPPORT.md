# Support

Public alpha support is best-effort. No email address, issue-tracker URL, service-level
target, or compatibility promise beyond the README contract has been configured.

For a reproducible problem, provide:

1. the exact command and whether the failure happened during install, setup, doctor,
   listen, benchmark, or browser use;
2. expected and observed behavior;
3. whether it reproduces after a new session without deleting the original session;
4. the privacy-filtered output of `he-ru report`;
5. the smallest synthetic reproduction possible.

Do not submit audio, transcripts, session logs, private loopback URLs, model files, or
personal paths by default. Review [SECURITY.md](SECURITY.md) for vulnerability reports.
Translation-quality requests need a separately approved and rights-cleared evaluation
corpus; a single anecdote is useful reproduction evidence but not a quality benchmark.
