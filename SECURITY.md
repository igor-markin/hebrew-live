# Security policy

This project is preparing a public alpha. No private vulnerability-reporting address or
security-advisory URL has been configured yet. That channel is a release blocker.

Until a private channel is published, do not post exploit details, private browser
URLs, audio, transcripts, logs, tokens, or local paths in a public issue. A reporter may
open a minimal issue that says a private channel is needed, without technical details.
The maintainer must then provide a private destination before evidence is transferred.

For ordinary reproducible bugs, use `he-ru report` and the issue template. Supported
security scope for the alpha is the Python CLI, loopback HTTP server, bundled browser
UI, local session storage, setup/download integrity controls, and public build/export
scripts. Model accuracy, harmful generated text, and upstream package/model defects
should still be documented, but they are not automatically vulnerabilities in this
codebase.

No response-time or disclosure-time promise is made until a maintainer and intake
channel are named.
